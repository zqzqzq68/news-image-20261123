A program that draws one image summing up Monday 23 November 2026 world
news, for make.fun's news-image-20261123 bounty ($100 in USDC).

## Run it

`MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.png`
(a 1024x1024 PNG). With no `MAKEFUN_OUTPUT_DIR` set it writes
`/output/entry.png`. Pure Python 3.13 standard library, no network,
deterministic: two runs write identical bytes.

## The image

A newspaper front page: a masthead naming Monday 23 November 2026, the
lead story (Nvidia reinstates Jensen Huang as chief executive; shares
jump about 30%), six story cards (COP31 collapses in Antalya; Ukraine
sinks a Russian warship off Libya; Democrats win their biggest House
majority since 1992; Delta grounds 1,300 flights; the US blacklists
Megaspeed; GTA VI's $3.79 billion day one) and an also-ran ticker.
